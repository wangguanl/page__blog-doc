什么是 Web Components ​

Web Components 是浏览器原生支持的组件化技术，由三部分组成：

  • Custom Elements（自定义元素）：定义可复用的 HTML 标签
  • Shadow DOM（影子 DOM）：封装样式和结构，避免冲突
  • HTML Templates（HTML 模板）：定义可复用的 HTML 片段

不依赖任何框架，所有现代浏览器原生支持。

Custom Elements 自定义元素 ​

定义自定义元素 ​

javascript
class MyButton extends HTMLElement {
  constructor() {
    super();
    this.innerHTML = '<button>点击我</button>';
  }
}

// 注册自定义元素，标签名必须包含连字符
customElements.define('my-button', MyButton);

使用：

html
<my-button></my-button>

生命周期回调 ​

javascript
class MyComponent extends HTMLElement {
  constructor() {
    super();
    console.log('构造函数：创建实例');
  }

  // 元素插入到 DOM 时
  connectedCallback() {
    console.log('已插入 DOM');
  }

  // 元素从 DOM 移除时
  disconnectedCallback() {
    console.log('已从 DOM 移除');
  }

  // 被移动到新文档时
  adoptedCallback() {
    console.log('已移动到新文档');
  }

  // 属性变化时
  attributeChangedCallback(name, oldValue, newValue) {
    console.log(`属性 ${name} 从 ${oldValue} 变为 ${newValue}`);
  }

  // 必须声明要监听的属性
  static get observedAttributes() {
    return ['color', 'size'];
  }
}

customElements.define('my-component', MyComponent);

属性与特性 ​

javascript
class MyCard extends HTMLElement {
  static get observedAttributes() {
    return ['title'];
  }

  attributeChangedCallback(name, oldValue, newValue) {
    if (name === 'title') {
      this.querySelector('.title').textContent = newValue;
    }
  }
}

使用：

html
<my-card title="标题"></my-card>
javascript
// 动态修改属性
el.setAttribute('title', '新标题');
el.getAttribute('title');

Shadow DOM 影子 DOM ​

Shadow DOM 将 DOM 和样式封装在元素内部，外部样式和脚本无法访问，内部样式也不会泄漏。

创建 Shadow DOM ​

javascript
class MyComponent extends HTMLElement {
  constructor() {
    super();

    // 开启 Shadow DOM
    const shadow = this.attachShadow({ mode: 'open' });

    shadow.innerHTML = `
      <style>
        /* 仅作用于 Shadow DOM 内部，不影响外部 */
        p { color: red; }
      </style>
      <p>Shadow DOM 内容</p>
    `;
  }
}

customElements.define('my-component', MyComponent);

mode 取值：

值说明
open可通过 element.shadowRoot 从外部访问
closed拒绝外部访问 element.shadowRoot 返回 null

样式封装 ​

Shadow DOM 内的样式不会影响外部，外部样式也不会影响内部：

javascript
shadow.innerHTML = `
  <style>
    :host { display: block; padding: 10px; } /* 设置宿主元素样式 */
    .inner { color: blue; }
  </style>
  <div class="inner">内部内容</div>
`;

:host 选择器选中自定义元素本身（Shadow DOM 宿主）。

HTML Templates 模板 ​

<template> 定义不会渲染的 HTML 片段，可通过 JS 克隆使用。

html
<template id="card-template">
  <style>
    .card { border: 1px solid #ddd; padding: 16px; }
  </style>
  <div class="card">
    <h3 class="title"></h3>
    <p class="content"></p>
  </div>
</template>
javascript
const template = document.getElementById('card-template');
const clone = template.content.cloneNode(true);

clone.querySelector('.title').textContent = '标题';
clone.querySelector('.content').textContent = '内容';

document.body.appendChild(clone);
  • template.content 获取模板内容（DocumentFragment）
  • cloneNode(true) 深克隆

slot 插槽 ​

<slot> 允许在自定义元素内部预留位置，由使用者在标签内填充内容。

默认插槽 ​

javascript
class MyCard extends HTMLElement {
  constructor() {
    super();
    const shadow = this.attachShadow({ mode: 'open' });
    shadow.innerHTML = `
      <div class="card">
        <slot>默认内容（未提供时显示）</slot>
      </div>
    `;
  }
}
customElements.define('my-card', MyCard);
html
<!-- 显示填充内容 -->
<my-card>
  <p>这是自定义内容</p>
</my-card>

<!-- 显示默认内容 -->
<my-card></my-card>

具名插槽 ​

javascript
shadow.innerHTML = `
  <div class="card">
    <header><slot name="header"></slot></header>
    <main><slot></slot></main>
    <footer><slot name="footer"></slot></footer>
  </div>
`;
html
<my-card>
  <h2 slot="header">标题</h2>
  <p>正文内容</p>
  <p slot="footer">页脚</p>
</my-card>

完整示例 ​

javascript
class UserCard extends HTMLElement {
  static get observedAttributes() {
    return ['name', 'avatar'];
  }

  constructor() {
    super();
    const shadow = this.attachShadow({ mode: 'open' });

    shadow.innerHTML = `
      <style>
        :host {
          display: inline-flex;
          align-items: center;
          gap: 8px;
          padding: 8px 16px;
          border: 1px solid #e0e0e0;
          border-radius: 20px;
        }
        img {
          width: 32px;
          height: 32px;
          border-radius: 50%;
        }
        .name { font-size: 14px; }
      </style>
      <img class="avatar">
      <span class="name"></span>
    `;
  }

  connectedCallback() {
    this.update();
  }

  attributeChangedCallback() {
    this.update();
  }

  update() {
    const shadow = this.shadowRoot;
    if (shadow) {
      shadow.querySelector('.name').textContent = this.getAttribute('name') || '';
      shadow.querySelector('.avatar').src = this.getAttribute('avatar') || '';
    }
  }
}

customElements.define('user-card', UserCard);

使用：

html
<user-card name="张三" avatar="avatar.png"></user-card>

自定义元素的扩展 ​

extends 内置元素 ​

javascript
class FancyButton extends HTMLButtonElement {
  constructor() {
    super();
    this.style.background = 'linear-gradient(45deg, #ff6b6b, #feca57)';
  }
}

// 扩展内置元素
customElements.define('fancy-button', FancyButton, { extends: 'button' });
html
<button is="fancy-button">漂亮的按钮</button>

检测元素是否已定义 ​

javascript
// 等待自定义元素定义完成
customElements.whenDefined('my-button').then(() => {
  console.log('my-button 已定义');
});

// 获取已定义的自定义元素
customElements.get('my-button');
