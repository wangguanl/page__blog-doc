Nodemon 热重载工具 ​

Nodemon 官方文档

Nodemon 是一款 Node.js 开发工具，能够监听文件变化并自动重启应用。它消除了开发过程中手动停止-启动服务器的繁琐操作，显著提升开发效率，是 Node.js 开发者的常用工具。

安装与使用 ​

bash
# 全局安装
npm install -g nodemon

# 或作为开发依赖安装
npm install --save-dev nodemon

# 基本用法：用 nodemon 替代 node 启动
nodemon app.js

# 指定监听目录
nodemon --watch src --watch lib app.js

# 延迟重启（避免频繁保存导致多次重启）
nodemon --delay 2 app.js

package.json 配置 ​

json
{
  "scripts": {
    "dev": "nodemon app.js",
    "dev:watch": "nodemon --watch src --ext js,ts,json",
    "start": "node app.js"
  },
  "devDependencies": {
    "nodemon": "^3.0.0"
  }
}
bash
# 使用 npm 脚本启动
npm run dev

nodemon.json 配置文件 ​

在项目根目录创建 nodemon.json 进行精细配置。

json
{
  "watch": ["src", "config"],
  "ext": "js,ts,json",
  "ignore": ["src/**/*.test.js", "dist"],
  "delay": "2000",
  "exec": "node --inspect app.js",
  "env": {
    "NODE_ENV": "development",
    "PORT": 3000
  },
  "verbose": true
}
配置项说明示例
watch监听的目录/文件["src"]
ext监听的文件扩展名"js,ts,json"
ignore忽略的文件/目录["dist", "*.test.js"]
delay重启延迟（毫秒）"2000"
exec执行命令"node app.js"
env环境变量{"NODE_ENV": "dev"}
verbose详细日志true

与 TypeScript 配合 ​

bash
# 方式1：使用 ts-node 直接运行
nodemon --exec ts-node src/index.ts

# 方式2：nodemon.json 配置
json
{
  "watch": ["src"],
  "ext": "ts",
  "ignore": ["src/**/*.spec.ts"],
  "exec": "ts-node src/index.ts"
}

与 Express 配合 ​

js
// app.js
const express = require('express');
const app = express();

app.get('/', (req, res) => {
  res.send('Hello, Nodemon!');
});

app.get('/api/time', (req, res) => {
  res.json({ time: new Date().toISOString() });
});

const PORT = process.env.PORT || 3000;
app.listen(PORT, () => {
  console.log(`Server running on port ${PORT}`);
});
bash
# 启动后修改代码，nodemon 自动重启
nodemon app.js

# 输出示例：
# [nodemon] restarting due to changes...
# [nodemon] starting `node app.js`
# Server running on port 3000

Nodemon vs 其他热重载方案 ​

工具适用场景特点
nodemonNode.js 服务端简单易用，文件变化即重启
ts-node-devTypeScript 项目专为 TS 优化，保留编译缓存
PM2生产环境进程管理 + 热重载，支持集群
webpack-dev-server前端开发HMR 热模块替换，不刷新页面
bash
# PM2 也支持开发模式热重载
pm2 start app.js --watch

# ts-node-dev（TypeScript 专用）
npm install -g ts-node-dev
ts-node-dev --respawn src/index.ts

手动重启 ​

bash
# 在 nodemon 运行时输入 rs 并回车，手动触发重启
# nodemon> rs
# [nodemon] restarting due to manual restart...

Nodemon 是 Node.js 开发中提升效率的基础工具。通过合理的监听配置，可以避免不必要的重启；配合 ts-node 能直接运行 TypeScript 源码。在生产环境中应使用 PM2 或容器编排工具替代 nodemon 进行进程管理。
