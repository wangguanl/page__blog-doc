无代码/低代码可视化搭建平台（Vue3 + Vite，从 0 到 1 主导开发） ​

业务场景 ​

29 家子公司每天产出专题设计图提交到总部，由开发人员做成运营活动页、落地页、专题页面再交付给子公司。总部拿到设计图进行运营和设计师的审核，审核通过后再排期制作，审核不通过则再沟通设计图错误并返回修改再如此反复。大量的页面开发占用了50%的开发资源，导致了人手紧缺、重复开发、沟通效率低等问题，则开发了无代码搭建平台，减少对开发团队的强依赖。

功能介绍 ​

无代码平台通过可视化拖拽操作 + 行业化模板库 + 融合物料体系，实现从需求到上线的全流程敏捷交付。将繁琐的底层架构和基础设施抽象化为图形界面，免去了代码编写工作，能够完全专注于业务场景。

技术栈 ​
  • 独立完成产品设计、前端架构、技术选型、功能开发与优化。
  • 前端架构基于 Vite + Vue3 + Pinia + Element Plus
  • 改良 draggable-resizable、draggable-sortable 实现组件在画布上的缩放与拖拽
  • 集成 Ace Editor、Highlight.js、Prettier、Monaco Editor 实现在线代码编辑与语法高亮
核心功能 ​
  • 可视化页面编辑器，覆盖页面构建、样式配置、交互管理与导出流程，所见即所得
  • 支持SEO，可自主编写SEO标题、搜索词、关键字
  • 设计通用组件库，建立前端规范体系
  • 拖拽画布、组件属性编辑、样式面板
  • 支持可视化 CSS 样式配置、动画设置、事件与交互面板
  • 设计 JSON Schema 驱动渲染，使用编译/反编译引擎 进行导入解析HTML，也可以导出HTML/CSS。并且可以使用 JSON Schema 配合引擎进行服务端渲染，可编辑代码。
  • 产出优化：图片懒加载、CDN优化
  • 支持PC、H5双端，可自适配
业务价值 ​
  • 缩短业务周期：减少制作流程，专题页面交付周期从 2天 缩短至 2~3小时，覆盖公司 95% 运营活动需求。
  • 极速交付：具有时效的专题不会因为排期等问题而错过档期。
  • 减少开发人力成本：使非专业开发人员也能参与到应用开发中，减少了对专业程序员的依赖，从而降低了开发人力成本。同时，由于开发效率的提高，也减少了项目开发过程中的人力投入和时间成本。
  • 降低技术维护成本：无代码平台生成的页面有较高的稳定性和可维护性，减少了因代码的不规范、复杂、质量不高导致的维护成本。而且方便对已生成的页面进行更新、升级和故障排查，降低了技术维护的难度和成本。
  • 提升转化：在生成的页面中埋点收集用户行为，通过页面停留时长、点击、浏览、滑动等行为偏好分析发现用户流失节点，推动改版后留存率提升。
  • 提升团队价值：让开发团队由典型的 成本导向型 转型 价值输出型
